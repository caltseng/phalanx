# Direct-session acceptance evidence

The direct path delivers PRs and reports through native writers. The combined live pilot
was accepted, but that acceptance does not certify every recovery drill or performance
target. The concise historical record and source references are in
[decisions](../decisions.md#direct-session-pilot-acceptance).

Future acceptance reports should distinguish independently read API/GitHub facts from
coordinator-supplied evidence. Bind results to the tested item, execution, writer, exact
revision, target and publication mode; record manual interventions and unresolved cases
rather than inferring a clean run from a merge. Store detailed run timelines with the
execution's report, not in the operating guides.

Use the [direct-session contract](../direct-sessions.md) for current behavior and
[Captain operating reference](../direct-path.md#captain-shifts-and-handoff) for continuity.
